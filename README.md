# TrackUnify – Android app download

TrackUnify is a team location and safety app: live map, site attendance, SOS alerts and team chat for managers, fleet owners and families.

This repository only hosts the app installer. It contains no source code.

## Install

1. On your Android phone, open the latest download:
   - Most phones: [TrackUnify.apk](https://github.com/rajivg2426-prog/trackunify-app/releases/latest/download/TrackUnify.apk)
   - Older phones (32-bit): [TrackUnify-older-phones.apk](https://github.com/rajivg2426-prog/trackunify-app/releases/latest/download/TrackUnify-older-phones.apk)
2. Open the downloaded file. If Android asks, allow "Install unknown apps" for your browser.
3. Open TrackUnify and sign up with your phone number.

You need a phone number for sign-in and, to join an existing team, the 6-character team code from your manager or parent.

All versions are listed under [Releases](https://github.com/rajivg2426-prog/trackunify-app/releases).
